# AutoFlow — один автомобіль, один маршрут

Аудиторія: власники українських автомайданчиків. Повідомлення: «Додали авто один раз. Далі працює AutoFlow».
Концепція, шість сцен і статичний v2 погоджені користувачем у поточній задачі. Уточнення: сцена 02 — «Додайте його в AutoFlow»; найновіше «для начала без озвучки» визначає це перше прев’ю: музика та SFX, без VO/TTS.

Цей етап створює лише локальне анімоване прев’ю. Фінальний файл/MP4 потребує окремого явного одобрення готового прев’ю. Жодних платних викликів, акаунтів, публікацій чи генерації.
