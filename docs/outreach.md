# Аутрич: продажа сайта-витрины автоплощадкам

Рабочая заметка по холодной рассылке. Цель: предложить площадкам/автосалонам
готовую сайт-витрину (под их бренд) + помощь с деплоем на их облако.

## Демо-ассеты

- **Живое демо (витрина):** https://autos-sale.com/
- **Демо-админка:** https://autos-sale.com/admin
  - Логин: `demo-editor@testmail.com`
  - Пароль: `Testpassword1!`
  - Роль: `editor` — видит/ведёт объявления и заявки; НЕ может трогать команду,
    брендинг, Telegram-токен, удалять объявления или менять пароль админа.
    Безопасно раздавать.
- ⚠️ Боевой `admin` в письма НЕ вставлять (полный доступ = получатель может
  залочить, удалить всё, создать своих админов). Держать при себе.

## Тон и правки (почему так)

- Ведём от боли/инсайта, не от продукта.
- «здається, у вас такого поки немає» — мягкая формулировка (не докор).
- «легка вітрина», не «лайтвейт листинг» — без англицизмов.
- Один мягкий CTA («що скажете?» / демо).
- Строку про кастомизацию — ПОСЛЕ демо (сначала «вот готовое», потом «и это
  ещё подгоним под вас»).

## Персонализация первой строки (поднимает ответы)

- «Бачив ваш Instagram / вашу площадку **[назва]**…»
- Не давать цену в первом сообщении — цель только «так, покажіть».
